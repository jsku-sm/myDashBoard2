생기부 교과세특 작성 흐름 수정

1. 학생과 학년도·학기·과목을 선택합니다.
2. 반영할 자료를 선택합니다. 읽기 쉬운 학습 내용·학생 응답·결과와 수식을 확인합니다.
3. AI 교과세특 초안 생성 버튼을 누릅니다. 사실 메모는 자동으로 채워지며 보완 입력은 선택 사항입니다.
4. 초안을 검토합니다. 그대로 사용하거나 필요한 부분만 수정합니다.
5. 완성본 확정 항목을 체크하고 완성본 저장을 누릅니다. 추가 메모·문장 수정은 필수가 아닙니다.

안내
- 생성 버튼을 누를 때에만 선택한 자료를 AI로 전송합니다. 자료 조회는 AI를 호출하지 않습니다.
- 실제 학생 응답과 게임의 성공 알림을 구분하며, 자료에 없는 풀이 과정·성취를 만들지 않습니다.
- 첨부파일만 있는 경우에는 원본을 확인하고 반영 내용을 보완해야 합니다.
- 원본 파일·학년도/학기/과목별 저장·이전 작성 이력·CSV 기능을 유지합니다.
- 기존 AI 연결 설정을 사용합니다. 이 작업에서 실제 학생 자료나 유료 AI를 호출하지 않았습니다.
- 배포 시 패치의 폴더 구조대로 코드 파일을 교체하거나 전체 ZIP을 사용하세요.

검증: 관련 187개 테스트 통과. 기존 로그인 문구/교사 메뉴 테스트 2개는 이전부터 현재 화면과 맞지 않아 제외했습니다. 모의 AI로 선택→생성→수정 또는 무수정 확정, 자료 변경/권한/저장 실패 처리까지 확인했습니다.
