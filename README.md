# 📐 구쌤의 수학 교실 — 수업용 대시보드

Streamlit으로 만든 수업용 웹앱입니다. 데이터는 **구글 시트**, 파일은 **구글 드라이브**에 저장합니다.

## 폴더 구성

```
app.py                  앱 시작 파일 (로그인, 잠금, 알림, 메뉴)
config.py               학급·단원·감정·기본 문구 설정
storage.py              저장소 (구글 시트/드라이브, 또는 로컬 시험용)
auth.py                 로그인·비밀번호
realtime.py             화면 잠금·접속 상태·상벌점 알림 (서버 메모리)
ui.py                   디자인(CSS), 폭죽, 잠금 화면
views/                  메뉴별 화면
students_template.csv   학생 명단 양식
get_drive_token.py      개인 지메일 드라이브 연결용 도우미
.streamlit/config.toml  테마
.streamlit/secrets.toml.example  비밀 설정 예시 (복사해서 사용)
```

> ⚠️ `.streamlit/secrets.toml`과 `data/` 폴더는 `.gitignore`에 들어 있어 깃허브에 올라가지 않습니다. 학생 정보와 비밀 키를 절대 깃허브에 올리지 마세요.

---

## 1단계. 내 컴퓨터에서 먼저 시험해 보기 (5분)

구글 설정 없이도 바로 실행됩니다. 이때 데이터는 `data/` 폴더에 저장됩니다.

```bash
pip install -r requirements.txt
streamlit run app.py
```

1. 교사 계정 `teacher` / `teacher1234`로 로그인한 뒤 새 비밀번호를 정합니다.
2. **교사전용 → 학생 명단**에서 `students_template.csv`를 올려 학생을 등록합니다.
3. 다른 브라우저(또는 시크릿 창)에서 학번 `10101`, 비밀번호 `10101`로 학생 로그인을 해 봅니다.
4. 교사 화면에서 잠금, 상점, 벌점을 눌러 학생 화면이 바뀌는지 확인합니다.

---

## 2단계. 구글 시트 연결 (서비스 계정)

1. [Google Cloud Console](https://console.cloud.google.com)에서 새 프로젝트를 만듭니다.
2. **API 및 서비스 → 라이브러리**에서 `Google Sheets API`와 `Google Drive API`를 **사용 설정**합니다.
3. **사용자 인증 정보 → 사용자 인증 정보 만들기 → 서비스 계정**을 만듭니다.
4. 만든 서비스 계정 → **키 → 키 추가 → JSON**을 선택해 키 파일을 내려받습니다.
5. 구글 드라이브에서 빈 구글 시트를 하나 만듭니다.
   - 이름은 자유롭게 정하면 됩니다(예: `수업대시보드_DB`).
   - **공유** 버튼을 눌러 JSON 안의 `client_email` 주소를 **편집자**로 추가합니다.
6. 시트 주소 `https://docs.google.com/spreadsheets/d/여기부분/edit`에서 `여기부분`을 복사합니다. 이것이 `spreadsheet_id`입니다.

탭(users, emotions, materials 등)은 앱이 처음 실행될 때 자동으로 만듭니다.

---

## 3단계. 구글 드라이브 연결 (파일 저장)

> 서비스 계정은 자기 저장 용량이 없어서, 일반 내 드라이브 폴더에는 파일을 올릴 수 없습니다. 아래 두 방법 중 하나를 고르세요.

### 방법 A. 학교 구글 워크스페이스의 **공유 드라이브**를 쓰는 경우

1. 공유 드라이브를 하나 만들고, 서비스 계정 이메일을 **콘텐츠 관리자**로 추가합니다.
2. 그 안에 폴더를 만들고, 폴더 주소 끝의 ID를 `drive_folder_id`에 적습니다.
3. secrets에서 `[gdrive_oauth]` 부분은 지웁니다.

### 방법 B. **개인 지메일** 드라이브를 쓰는 경우

1. Cloud Console에서 **OAuth 동의 화면**을 설정합니다.
   - 사용자 유형은 '외부'를 고릅니다.
   - **게시 상태를 '프로덕션'으로 변경**합니다. '테스트' 상태로 두면 7일마다 연결이 끊깁니다.
2. **사용자 인증 정보 → OAuth 클라이언트 ID → 데스크톱 앱**을 만듭니다.
3. JSON을 내려받아 `client_secret.json`이라는 이름으로 이 폴더에 저장합니다.
4. 내 컴퓨터에서 아래를 실행하고, 브라우저가 열리면 교사 계정으로 허용합니다.
   ```bash
   pip install google-auth-oauthlib
   python get_drive_token.py
   ```
   - "확인되지 않은 앱" 경고가 뜨면 **고급 → 이동**을 누르면 됩니다.
5. 화면에 출력된 `[gdrive_oauth]` 세 줄을 secrets에 붙여 넣습니다.
6. `drive_folder_id`는 비워 둡니다. 앱이 내 드라이브에 `수업대시보드_파일` 폴더를 직접 만들어 사용합니다.

> 업로드한 **학습지와 평가계획**은 '링크가 있는 모든 사용자'로 공유되어 학생이 바로 내려받습니다. 학교 정책상 외부 공유가 막혀 있으면, 앱을 거쳐 내려받도록 자동으로 바뀝니다. **학생 결과물**은 공유하지 않고 교사만 앱에서 열 수 있습니다.

## 4단계. secrets 작성

`.streamlit/secrets.toml.example`을 복사해 `.streamlit/secrets.toml`로 저장하고 값을 채웁니다.

- `storage = "google"`으로 설정합니다.
- 교사 아이디와 처음 비밀번호를 적습니다.
- `spreadsheet_id`를 적습니다.
- 서비스 계정 JSON의 각 값을 `[gcp_service_account]`에 옮겨 적습니다.
  - `private_key`의 줄바꿈 `\n`은 그대로 둡니다.
- 방법 B를 골랐다면 `[gdrive_oauth]`를 적습니다.

교사 계정은 시트에 교사가 한 명도 없을 때 secrets 값으로 **한 번만** 만들어집니다. 그 뒤에는 앱의 **내 정보**에서 비밀번호를 바꾸세요.

---

## 5단계. 깃허브에 올리고 배포하기

1. 깃허브에 새 저장소를 만들고 이 폴더를 올립니다. 학생 정보가 걱정되면 **Private** 저장소를 권장합니다.
2. [share.streamlit.io](https://share.streamlit.io)에서 깃허브로 로그인합니다.
3. **New app**을 눌러 저장소를 고르고, Main file을 `app.py`로 지정합니다.
4. **Advanced settings → Secrets**에 `secrets.toml` 내용을 그대로 붙여 넣고 **Deploy**합니다.
5. 생성된 주소를 학생들에게 안내합니다.

## 사용 안내

### 학생

- 첫 로그인 때 비밀번호는 **학번**이고, 바로 새 비밀번호로 바꿔야 들어갈 수 있습니다.
- 하루 첫 로그인 때 감정을 고르는 화면이 뜹니다.
- 비밀번호를 잊으면 교사가 **교사전용 → 학생 명단**에서 초기화합니다. 초기화하면 다시 학번이 비밀번호가 됩니다.

### 교사

| 기능 | 위치 |
|---|---|
| 감정·접속 현황 | 대시보드 |
| 학습지·평가계획 올리기 | 공통수학1·2 탭 |
| 학생 결과물 확인·한마디 | 공통수학 → 학급 게시판 |
| 질문 답변 | 공통수학 → 질문 게시판 |
| 화면 잠금/해제 | 수업도구 맨 위 (학급 선택 가능). 잠금 중이면 사이드바에 '모두 잠금 해제' 버튼이 생김 |
| 관찰기록·상벌점·명단·설정 | 교사전용 |
| 소개 문구·도구 링크·수다노트 링크 | 각 화면의 ✏️/⚙️ 펼치기 |

### 알아 둘 점

**반응 속도**
- 학생 화면은 4초마다 상태를 확인합니다.
- 그래서 잠금, 폭죽, 벌점 안내는 몇 초 늦게 나타납니다.

**잠금 범위**
- 잠금은 **이 앱 안에서만** 적용됩니다.
- 학생이 따로 연 다른 사이트 탭은 잠그지 못합니다.

**접속 상태**
- 화면을 연 채로 있으면 '접속 중'으로 표시됩니다.
- 창을 닫으면 약 1분 30초 뒤 '미접속'으로 바뀝니다.

**앱이 재시작될 때**
- 잠금 상태와 '접속 중' 정보는 서버 메모리에 있어서, 앱이 재시작되면 초기화됩니다(잠금 해제 상태).
- 기록 데이터는 구글 시트에 남습니다.

**알림을 놓치는 경우**
- 학생이 접속하지 않은 상태에서 준 상벌점은 기록에는 남지만, 폭죽이나 안내 창은 표시되지 않을 수 있습니다.

**다시 로그인해야 하는 경우**
- 브라우저를 새로고침하면 다시 로그인해야 합니다.

### 무료 Streamlit Cloud 사용 시

- 앱 메모리는 약 1GB입니다.
- 한 학급(30명 내외)이 동시에 쓰는 정도는 문제없습니다.
- 며칠 동안 아무도 접속하지 않으면 앱이 잠들고, 첫 접속 때 깨우는 데 30초쯤 걸립니다. 수업 전에 한 번 열어 두세요.
