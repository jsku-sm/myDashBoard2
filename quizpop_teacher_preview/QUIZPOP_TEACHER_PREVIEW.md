# 교사용 전체 문제 확인

## 적용 방법

1. `quizpop_teacher_preview.zip` 압축을 풉니다.
2. GitHub `jsku-sm/myDashBoard2`의 `app.py`가 있는 첫 화면에서 **Add file → Upload files**를 선택합니다.
3. 압축을 푼 **quiz_pop 폴더 전체**를 끌어 넣고 **Commit changes**를 누릅니다. 기존 폴더를 삭제할 필요는 없습니다.
4. Streamlit 갱신 후 새로고침합니다. 이전 화면이 계속 보이면 **Manage app → Reboot app**을 누르고 다시 로그인합니다.

Python 파일과 `frontend/index.html`, `frontend/assets`를 함께 교체해야 합니다. ZIP 자체를 저장소에 올리는 것만으로는 적용되지 않습니다. 이번 ZIP에는 이전 참여코드 자동 발급 수정도 포함되어 있습니다.

## 교사가 만든 퀴즈 확인

**5. 수업도구 → 4. 퀴즈**에서 퀴즈를 생성한 뒤 **생성한 문제 전체 확인 · 정답·해설**을 펼치세요.

- 전체 문항과 5개 보기를 한 화면에서 확인합니다.
- 문제 번호를 누르면 해당 문항으로 이동합니다.
- 각 문항의 **정답·해설 확인**을 펼치면 정답 번호, 정답 보기, 해설, 핵심 개념, 단계별 힌트가 나옵니다.
- **정답·해설 모두 보기 / 모두 숨기기**로 한꺼번에 표시를 바꿀 수 있습니다. 처음에는 정답을 숨깁니다.
- 수식은 LaTeX로 렌더링하고, 대응 그림 등 문항의 시각 자료도 함께 표시합니다.

이전에 만든 퀴즈는 **배포한 퀴즈 · 문제와 학생 결과 다시 열기**에서 선택하고 **문제·참여코드·학생 결과 열기**를 누르세요. 새 퀴즈를 만든 뒤에도 이전 참여코드에 배포된 원래 문항을 확인할 수 있으며, 참여 종료 후에도 열람 가능합니다.

이 화면은 퀴즈를 만든 교사에게만 제공됩니다. 열람은 학생의 답안·진행률을 바꾸거나 AI 출제를 다시 요청하지 않습니다. 학생 참여코드와 `jsku-sm/class-dashboard-data` 저장 구조는 유지됩니다.

## 검증 범위

자동 테스트로 교사 생성 → 코드 발급 → 전체 문항 확인 → 학생 참여와 답안 저장 → 교사 결과 및 종료 후 원본 문항 열람을 확인했습니다. 학생과 다른 교사의 열람 차단, 수식과 대응 그림, 정답 표시 전환, 화면 갱신 중 펼침 상태 유지도 검사했습니다.

AI·GitHub 전송은 테스트용 응답을 사용했습니다. 실제 배포 서버를 변경한 것은 아니므로 위 업로드 절차를 진행해야 합니다.
