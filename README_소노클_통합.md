# myDashBoard2 · 수업도구 → 3. 수행평가 통합본

## 1. 적용 방법

기존 대시보드 파일을 먼저 백업하세요. 이 ZIP은 **압축을 풀어 그 안의 파일과 폴더를 올리는 용도**입니다. ZIP 자체를 GitHub에 올려 실행하는 방식이 아닙니다.

1. 압축을 풀고 `myDashBoard2` 폴더를 엽니다.
2. 폴더 **안의 내용**을 기존 myDashBoard2 GitHub 저장소의 최상위 위치에 덮어씁니다. `app.py` 옆에 `think_app`, `views`, `requirements.txt`가 있어야 합니다.
3. Streamlit Community Cloud의 실행 파일은 기존처럼 `app.py`로 유지합니다. `streamlit_app.py`로 배포된 경우에도 통합 대시보드를 실행하도록 호환 진입점을 넣었습니다.
4. 앱을 재시작하고 로그인한 뒤 **수업도구 → 3. 수행평가**을 누릅니다.

`requirements.txt`를 반드시 함께 바꾸세요. 소노클의 녹음·이미지·그래프·AI 관련 라이브러리가 추가되어 있습니다. 새 패키지 설치가 진행되는 동안에는 배포 로그를 확인하세요.

기존 `Settings → Secrets`의 `[app]`, `[github]` 값은 지우지 마세요. 실제 `.streamlit/secrets.toml`과 데이터 폴더는 이 통합본에 포함하지 않았습니다. 예시 파일을 실제 비밀값 파일로 바꾸어 GitHub에 올리면 안 됩니다.

## 2. 달라진 동작

**기존:** 수업도구의 스노클 링크가 외부 사이트를 엽니다.

**통합본:** ‘3. 수행평가’을 누르면 업로드하신 snorkl 앱의 수업·활동 화면이 **같은 Streamlit 대시보드 안에서 실행**됩니다. 별도 앱 주소나 두 번째 서버가 필요하지 않습니다.

수업도구 상단에 **1. 데스모스 · 2. 데스모스 액티비티 · 3. 수행평가 · 4. 퀴즈 · 5. 앱 (by Good쌤)** 메뉴가 표시됩니다. 원하는 메뉴를 클릭하면 해당 내용만 열리며, 다른 메뉴를 클릭해 바로 이동할 수 있습니다. 기존 소노클 수업 공유 주소는 **3. 수행평가**를 바로 엽니다. 대시보드의 왼쪽 메뉴도 유지됩니다. 소노클의 독립 실행용 사이드바와 중복 페이지 설정은 실행하지 않습니다.

교사는 수업 만들기·수정·삭제, 활동 만들기, 손글씨/퀴즈/그래프 활동, 학생 답안 확인, 교사 피드백, 평가, 자료 내보내기를 사용합니다. GitHub 모드에서는 수업 보관·복원도 사용할 수 있습니다.

학생은 대시보드에 등록된 학번·이름·반을 그대로 사용합니다. 학생이 참여 정보를 다른 사람으로 바꾸는 독립 앱의 입력창은 통합 경로에서 호출하지 않습니다. 등록된 반의 수업만 열고 자신의 답안과 피드백을 확인하도록 연결했습니다. 교사 화면의 ‘학생으로 체험해보기’는 교사에게만 표시됩니다.

기존 로그인, 최초 비밀번호 변경, 감정 체크, 대시보드 입력 잠금은 소노클로 들어가기 전에 적용됩니다. 공유 주소도 로그인과 반 확인을 통과해야 합니다. 주소의 `role`이나 `student_id` 같은 값은 권한으로 사용하지 않습니다.

## 3. 처음 실행할 때

수행평가의 저장 모드를 따로 지정하지 않으면 기존 대시보드의 GitHub 저장소·토큰을 재사용해 **비공개 GitHub에 자동 저장**합니다. GitHub 연결이 없으면 서버의 `.think_data/`에 암호화해 저장합니다. 통합 화면의 기존 `demo` 설정도 이 지속 저장 방식으로 처리합니다. AI 키나 Desmos API 키는 수업·활동 저장에 필요하지 않습니다.

**수행평가 만들기·활동 저장·답안 제출로 저장한 자료는 앱을 다시 실행하면 불러옵니다.** 수업, 문제·모범답안·평가 기준, 배포·타이머 상태, 문제 파일과 학생 첨부, 제출 답안과 피드백을 보관합니다. 새 보관 공간의 암호화 키는 한 번만 생성해 같은 저장소에서 재사용하며, 기존 키를 설정한 운영 공간은 그 키를 유지합니다.

Streamlit Cloud에서는 로컬 파일이 계속 남는다고 보장하지 않으므로 기존 `[github]`의 `repo`·`token`을 연결하거나 아래 GitHub 저장 설정을 사용하세요. [공식 저장소 안내](https://docs.streamlit.io/develop/concepts/connections/connecting-to-data)

업데이트할 때 현재 프로세스 메모리에 남아 있는 자료는 첨부·원본 제출 파일과 함께 새 보관 공간으로 이전합니다. 기존 저장 자료와 충돌하면 덮어쓰지 않고 오류를 표시합니다. 이미 종료되어 사라진 메모리 자료는 복원할 수 없습니다. 저장 버튼을 누르기 전 입력은 별도의 영구 저장 대상이 아닙니다.

교사는 시험 수업을 만들어 대상 반을 선택하고 활동을 등록한 뒤 **학생에게 배포**를 누릅니다. 수행평가 기간 안에 시험용 학생 계정으로 같은 반에 로그인하여 제출하고, 교사 계정으로 답안을 확인하세요. 이 ZIP에는 실제 학생 명단이나 테스트용 학생 계정이 들어 있지 않습니다.

## 4. 소노클 자료를 GitHub에 계속 보관하기

### 대시보드와 같은 비공개 데이터 저장소를 사용하는 경우

기존 Streamlit Secrets의 `[app]`, `[github]` 연결을 그대로 사용하면 새 수행평가 보관 공간은 자동으로 설정됩니다. 저장 모드를 명시하려면 아래 **섹션 하나**를 추가합니다. 이미 `[snorkl]`이 있으면 새로 추가하지 말고 그 안의 값을 수정하세요.

```toml
[snorkl]
mode = "github"
ai_enabled = false
# 기존 암호화 자료를 불러올 때만 원래 encryption_key를 추가합니다.
```

이때 저장소 이름·브랜치·토큰은 대시보드의 `[github]`에서 가져옵니다. 대시보드의 CSV 저장 형식은 그대로 두고, 소노클 자료는 `think-learning-v1/` 아래의 원래 암호화 형식으로 따로 저장합니다. 원본 앱에 들어 있던 GitHub 비공개 확인과 동시 저장 재시도 로직도 유지합니다.

암호화 키를 지정하지 않은 새 보관 공간은 `think-learning-v1/.encryption.key`를 같은 비공개 저장소에 한 번 생성합니다. 이후 재시작하거나 토큰을 교체해도 이 키를 읽으며, 동시 첫 실행에서도 먼저 저장한 키를 덮어쓰지 않습니다. 키도 저장소 접근 권한으로 보호되므로 저장소를 비공개로 유지하세요. 키를 자료와 분리해 관리하려면 처음부터 `[snorkl] encryption_key`에 별도 키를 지정할 수 있습니다.

기존 `state.enc`가 있는데 자동 키 파일과 명시한 키가 모두 없으면 새 키를 만들지 않고 원래 키를 요청합니다. 키를 직접 생성하는 경우에는 다음 명령을 개인 컴퓨터의 비공개 환경에서 실행하고 안전하게 보관하세요.

```bash
python generate_snorkl_key.py
```

**이미 자료를 저장한 소노클의 암호화 키를 새 키로 교체하지 마세요. 이전 키가 없으면 기존 자료를 복호화할 수 없습니다.**

### 기존 소노클이 다른 비공개 저장소를 사용한 경우

같은 `[snorkl]` 안에 원래 값들을 지정합니다.

```toml
[snorkl]
mode = "github"
github_repo = "내아이디/기존-소노클-데이터저장소"
github_branch = "main"
github_token = "원래 저장소에 접근 가능한 토큰"
encryption_key = "원래 소노클의 Fernet 키"
ai_enabled = false
```

원본 소노클의 최상위 `THINK_MODE`, `GITHUB_REPO`, `GITHUB_BRANCH`, `GITHUB_TOKEN`, `ENCRYPTION_KEY`, `AI_ENABLED`, `OPENAI_API_KEY`, `OPENAI_MODEL`, `TRANSCRIPTION_MODEL`, `DESMOS_API_KEY` 설정도 읽을 수 있게 했습니다. `[snorkl]`에 같은 항목을 지정하면 그 값이 우선합니다. 대시보드의 `[app]` 설정은 원래 대시보드용으로 유지합니다.

**자동 자료 이전 작업을 한 것은 아닙니다.** 같은 저장소·브랜치·키를 지정해야 같은 소노클 기록을 읽습니다. 원본의 `1반`~`7반`과 대시보드의 `1-1`~`1-7` 모두 지원하며, 기존 반 표기는 저장된 그대로 유지합니다. 기존 반 표기를 바꾸면 과거 답안의 반 정보와 달라질 수 있으므로 자료를 옮기는 과정에서 불필요하게 변경하지 마세요.

통합본은 교사 계정들을 한 학교의 공동 관리자로 취급합니다. 교사별 소유 수업을 따로 나누는 다중 학교 서비스로 변경한 것은 아닙니다.

기존 로그인 없는 독립 소노클 앱이 같은 데이터 저장소로 여전히 배포되어 있으면, 그 앱의 접근 경로도 남아 있습니다. 통합 앱의 로그인 보호가 옛 배포 앱을 자동으로 보호하지는 않습니다. 실제 학생 기록을 사용하기 전 옛 앱의 접근 범위도 확인하세요.

## 5. AI 및 Desmos 설정

AI 없이도 답안·손글씨·이미지·PDF·녹음을 제출하고 교사가 직접 피드백하는 코드는 사용할 수 있습니다. 음성 전사와 AI 피드백에는 별도 API 설정이 필요합니다. 기존 `[snorkl]`에 아래 필드를 추가합니다. 섹션 이름을 중복 입력하지 마세요.

```toml
ai_enabled = true
openai_api_key = "실제 값은 Streamlit Secrets에만 입력"
openai_model = "gpt-4.1-mini"
transcription_model = "gpt-4o-mini-transcribe"
# 필요할 때만 설정
# desmos_api_key = "사용 조건을 확인한 Desmos Calculator API 키"
```

이 필드들은 **`[snorkl]` 섹션 안**에 있어야 합니다. 비밀번호·토큰·API 키를 채팅이나 공개 저장소에 올리지 마세요.

**수행평가 활동 추가:** ‘직접 쓰며 풀기’에서 학생에게 보여 줄 PDF, DOCX, TXT, MD 또는 이미지 문제 파일을 첨부할 수 있습니다. 문제 파일은 최대 5개, 파일당 10MB까지 저장하며 학생 화면에서 확인·다운로드할 수 있습니다. 한글(HWP) 문서는 PDF나 DOCX로 저장해서 올려주세요.

모범답안 자동 작성은 다음 순서로 사용합니다.

1. 문제 파일을 첨부하면 **문제 파일을 OpenAI로 분석해 모범답안 자동 작성** 체크박스를 선택할 수 있습니다.
2. 교사가 체크하면 현재 첨부한 문제를 OpenAI로 보내 분석합니다. 서버의 `[snorkl] openai_api_key` 또는 환경변수·최상위 Secrets의 `OPENAI_API_KEY`를 재사용하며, 이 설정이 없으면 기본 OpenAI 주소를 사용하는 기존 생기부 생성기의 `[openai] api_key`도 사용할 수 있습니다. 학생 AI 피드백 설정인 `ai_enabled = false`도 교사의 이 기능 사용을 막지 않습니다.
3. 서버 API 키가 없으면 표시되는 비밀번호 입력란에 OpenAI API 키를 입력합니다. 키를 입력하면 현재 첨부한 문제의 모범답안을 자동 작성합니다. 입력한 키는 현재 교사의 로그인 세션에만 보관하고 로그아웃하면 지웁니다. 문제 파일, 활동, 학생 답안 스냅샷 또는 공유 저장소에 기록하지 않습니다.
4. 생성 결과는 **모범답안** 입력란에 자동으로 표시됩니다. 교사가 읽고 수정한 뒤 **활동 저장**을 누르세요.

체크한 상태에서 새 문제 파일을 첨부하면 다시 분석합니다. 같은 파일로 화면만 새로 그릴 때는 추가 API 요청을 보내거나 교사가 수정한 답안을 덮어쓰지 않습니다. AI 분석에 실패해도 작성 중인 모범답안을 유지하며, **문제 파일로 모범답안 다시 작성** 버튼으로 재시도할 수 있습니다. 체크하지 않은 파일은 자동 작성 목적으로 OpenAI에 전송하지 않습니다. 이 선택은 학생의 AI 피드백 설정을 변경하지 않습니다.

평가 기준에서는 2022 개정 수학과 교육과정의 과목·단원·성취기준을 선택하면 ‘평가 기준 · 한 줄에 하나’에 자동 입력됩니다. 추가 평가 기준을 직접 입력할 수도 있으며, 전체 기준은 최대 8개입니다. 새 활동의 최대 시도 횟수는 2회이고 기존 활동의 설정은 유지됩니다. 문제 파일이 첨부된 활동은 교사가 직접 평가합니다.

**학생에게 배포:** 새 활동은 **배포 전** 상태로 저장됩니다. 문제와 모범답안, 평가 기준, 시작일·마감일을 확인한 뒤 활동 목록의 해당 카드나 활동 상세 화면에서 **학생에게 배포**를 누르세요. 상태 선택만 ‘진행 중’으로 바꾸면 학생에게 배포되지 않습니다. 숨김이나 보기만 가능 상태로 바꾼 배포 활동은 **학생에게 다시 배포**로 공개를 재개할 수 있습니다.

학생에게는 배포된 활동만 지정된 수행평가 기간에 열립니다. 시작일과 마감일은 한국 시간 기준이며 두 날짜를 포함합니다. 열 수 있는 활동이 없거나 기간이 지난 활동 주소로 들어오면 **수행평가 기간이 아닙니다.**라는 안내가 표시됩니다.

교사가 수행평가 타이머에서 **평가 종료**를 누르면 학생 화면에 정확히 **선생님이 평가를 종료했습니다.**를 표시하고 해당 활동의 문제·첨부 파일·답안 입력을 숨깁니다. 이후 마감일이 지나도 교사의 종료 안내를 유지합니다. 같은 수업에 다른 진행 중인 활동이 있으면 활동 선택에서 그 활동으로 이동할 수 있습니다. 교사가 종료하지 않은 활동에서 풀이 시간이 자연스럽게 만료되거나 수행평가 기간이 지나면 기존의 **수행평가 기간이 아닙니다.** 안내를 표시합니다. 숨김 또는 미배포 활동의 종료 여부는 학생에게 공개하지 않습니다.

**종료한 평가 재개:** 교사는 수행평가 타이머에서 재개할 남은 풀이 시간을 양수로 지정하고 **평가 재개**를 눌러 언제든 다시 열 수 있습니다. 재개한 시점부터 지정한 시간으로 타이머가 시작되고 종료 기록이 해제됩니다. 시작일·마감일이 현재 날짜를 포함하지 않으면 필요한 범위만 확장하며, 최초 배포 기록과 기존 제출·피드백·첨부 PDF 및 이미지·시도 횟수는 유지합니다. 학생의 종료 안내 화면에서도 2초마다 재개 여부를 확인하고, 재개되면 종료 안내를 없애고 문제·답안 입력 화면을 다시 표시합니다.

재개 시간이 자정을 넘으면 마감일도 해당 시간이 끝나는 날짜까지 포함합니다. 같은 로그인 세션에서는 제출 전 작성하던 글·퀴즈 답·풀이판·저장 파일 선택·녹음과 수정한 음성 설명을 복원합니다. 데스모스 SDK를 연결한 그래프는 수식 상태도 복원하며, 외부 데스모스 페이지를 사용하는 경우에는 캡처 이미지나 작업 파일을 따로 저장하세요. 재개해도 최대 시도 횟수는 초기화되지 않습니다.

미래 시작일을 지정한 활동도 미리 배포할 수 있습니다. 시간 제한이 없으면 시작일부터 학생이 참여할 수 있습니다. 풀이 시간을 설정한 활동은 기간 안에 배포하면 모든 학생의 타이머가 동시에 시작됩니다. 미래 기간에 예약 배포한 제한시간 활동은 시작일에 교사가 **평가 시작**을 눌러야 학생이 참여할 수 있습니다. 기존에 저장된 진행 중·보기만 가능 활동은 기존 공개 상태를 유지하면서 기간과 타이머 조건을 적용합니다.

학생 수행평가 화면에는 ‘내 소노클 수업’ 제목을 표시하지 않습니다. 활동 화면의 **이전메뉴로 돌아가기**를 누르면 참여할 수 있는 수업 목록으로 돌아갑니다.

**학생 답안 첨부:** PNG·JPG 이미지와 PDF를 합쳐 최대 2개 첨부할 수 있습니다. PDF는 파일당 10MB 이하, 1~200쪽이어야 하며 암호가 설정된 PDF는 받지 않습니다. 로그인한 학생의 파일은 업로드할 때 저장되고 답안에 첨부해 제출할 수 있습니다. 학생과 교사 모두 저장한 PDF 원본을 내려받을 수 있으며, **내 작업 ZIP 저장**에도 첨부 PDF 원본을 그대로 포함합니다.

학생 답안 작성 화면에는 AI 피드백 선택 항목과 음성 자동 변환 버튼을 표시하지 않습니다. 학생이 제출한 글·이미지·PDF·녹음·직접 작성한 음성 설명은 저장되고 교사가 직접 평가합니다. 이 화면에서 제출한 답안은 자동 AI 분석을 실행하지 않습니다.

Desmos 키가 없을 때의 기본 계산기 보기/첨부 제출 방식은 원본 코드를 유지했습니다. API를 통한 그래프 상태 저장·복원과 브라우저 화면 캡처는 실제 API 이용 조건과 브라우저 지원을 별도로 확인해야 합니다. 통합 작업이 해당 기능의 이용권이나 API 키를 발급하는 것은 아닙니다.

마이크·펜·파일 선택은 실제 학생 기기의 브라우저 권한과 동작을 확인하세요. 특히 실제 아이패드의 마이크, 손글씨, 그래프 조작은 이번 작업 환경에서 시험하지 못했습니다.

## 6. 문제 확인

| 증상 | 확인할 것 |
|---|---|
| 기존 외부 스노클 링크가 그대로 보임 | `views/tools.py`가 교체됐는지, 올바른 저장소/브랜치가 배포됐는지 확인 |
| 소노클 라이브러리 안내가 뜸 | `requirements.txt` 및 `think_app` 전체 업로드 후 패키지 설치 로그 확인 |
| 빈 화면 | 실행 파일이 `app.py` 또는 통합본 `streamlit_app.py`인지 확인 |
| 학생에게 수업이 보이지 않음 | 교사 수업의 참여 반과 학생 계정의 반을 비교 |
| 교사에게 보이는 활동이 학생에게 안 보임 | ‘학생에게 배포’를 눌렀는지, 시작일·마감일과 타이머를 확인. ‘숨김’이나 ‘배포 전’ 활동은 학생에게 열리지 않음 |
| 학생에게 ‘수행평가 기간이 아닙니다.’가 표시됨 | 학생 반에 배포된 활동이 있는지, 한국 시간 기준 활동 기간에 해당하는지, 제한시간 평가가 시작되었는지 확인 |
| 학생에게 ‘선생님이 평가를 종료했습니다.’가 표시됨 | 교사가 해당 활동의 수행평가 타이머에서 ‘평가 종료’를 누른 상태. 다시 진행하려면 교사가 남은 풀이 시간을 정하고 ‘평가 재개’를 누름 |
| 재시작 후 자료가 보이지 않음 | 이전과 같은 저장소·브랜치·키인지 확인. Streamlit Cloud에서는 `[github]`의 repo·token을 연결하고, 수행평가의 명시적 `local` 설정은 `github`로 변경 |
| 복호화 오류 | 이전에 사용한 저장소·브랜치·Fernet 키인지 확인. 임의 키 교체 금지 |
| 제출이 지연됨 | GitHub 연결·요청 제한 확인. 원본은 실패 시 재시도 안내를 표시하며 입력을 유지하도록 구성됨 |
