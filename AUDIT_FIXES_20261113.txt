Good쌤 수학교실 · 점검 후 코드 보완 (2026-11-13)

이번 적용 범위
1. 퀴즈팝: 서버·화면·교사용 문제 확인·참여코드 상태가 같은 버전으로 동작하는 파일 묶음입니다.
   일부 파일만 올리면 버전 불일치를 표시합니다. 원본 JavaScript도 포함합니다.
2. 생기부: 단계별 개념퀴즈 전 단원과 20개 아케이드의 학습 이벤트를 근거 목록에 연결합니다.
   개념퀴즈는 실제 저장된 문제·학생 답·자동 정오를 표시합니다.
   아케이드는 문제를 포함한 성공·오류·힌트 이벤트만 표시하고, 브라우저가 보낸 기록임을 구분합니다.
   게임 점수·순위·코인·게임 시작/일시정지/승리만으로 교과 성취를 추정하지 않습니다.
   날짜·과목 필터와 교사 확인 절차, 기존 아바타 학습게임은 유지합니다.
   저장소의 현재 프로필에 남은 기록을 불러옵니다. 이미 잘려 나간 오래된 이벤트를 복원한 것은 아닙니다.
3. 저장 안내: 학생 등록·명단 수정·삭제·비밀번호 변경/초기화·설정은 원격 저장 확인 후 완료를 표시합니다.
   저장 실패 시 재시도는 같은 작업을 반복하지 않고 대기 중인 변경을 저장합니다.
   저장 대기 상태에서 다음 계정 변경을 겹쳐 실행하지 않도록 안내합니다.
4. 계정 파일 등 로컬 운영 자료가 새로 코드에 추가되지 않도록 .gitignore를 보완했습니다.
   이미 Git에 올라간 data/users.csv와 과거 이력은 이것만으로 제거되지 않습니다.
5. 학생 식별: student_identity/와 scripts/preview_student_identity.py는 검토용 준비 코드입니다.
   운영 로그인·기존 데이터 경로는 아직 전환하지 않았습니다.

코드 올릴 위치
- 코드 저장소: jsku-sm/myDashBoard2
- 데이터 저장소 jsku-sm/class-dashboard-data에는 이 코드 묶음을 올리지 마세요.
- 전체 ZIP을 풀면 나오는 myDashBoard2-main 폴더 안의 내용을 코드 저장소 루트의 같은 위치에 적용합니다.
- quiz_pop은 폴더 전체를 같은 경로에 적용합니다. 별도의 quizpop_teacher_preview 하위에 넣으면 적용되지 않습니다.
- 부분 패치를 쓸 때도 patch ZIP 안의 app.py와 각 폴더가 저장소 루트에 바로 연결되어야 합니다.
- 기존 학생 자료·Secrets·암호화 키를 삭제하거나 새 키로 교체하지 마세요.
- 전체 묶음과 부분 패치 모두 계정·학생 데이터·Secrets를 포함하지 않습니다.

확인 방법
1. 교사 퀴즈 생성 → 6자리 참여코드 표시 → 생성한 문제 전체 확인에서 문제·정답·해설 확인.
2. 학생 참여코드 입장 → 풀이 → 새로고침 후 이어하기. AI 생성에는 기존 Secrets의 설정이 필요합니다.
3. 생기부 생성기에서 대상 학생·2026학년도·학기·과목 선택 → 기존 자료 동기화 → 근거 목록 확인.
4. 학생 명단에서 목록 클릭과 학생 선택이 같은 학생을 가리키는지 확인.
5. 비밀번호 변경과 명단 수정의 저장 완료 표시 확인. 실패하면 저장 확인 다시 시도를 사용합니다.

아직 처리하지 않은 운영 변경
- 실제 데이터 저장소에 학생 고유번호 대응표를 쓰거나 기존 자료를 옮기는 작업.
- 공개 코드의 계정 파일 삭제, 과거 Git 이력 재작성, 저장소 공개 범위 변경.
- 실제 교사 비밀번호 변경, 암호화 키 교체.
이 작업들은 별도 확인 대상입니다. 이번 코드 묶음을 준비하면서 실제 GitHub와 학생 데이터는 수정하지 않았습니다.

교사 계정은 삭제·재생성하지 않고 기존 ID를 유지해야 관찰기록과 생기부 작성자 연결을 보존하기 쉽습니다.
실제 수업용 계정의 비밀번호는 앱의 내 정보에서 직접 변경하고 원격 저장 완료를 확인하세요.
